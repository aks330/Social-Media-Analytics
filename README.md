# Social Media Analytics Using Python

## Project Overview
This project analyzes Instagram social media data using Python
to explore engagement patterns and identify useful insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Excel

## Project Files
- `social_media_dashboard.py` - Python analysis and visualization script.
- `Instagram_Analytics.xlsx` - Dataset used for analysis.
- `Figure_1.png` - Generated visualization.

## Key Activities
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Analysis of social media metrics
- Data visualization using Matplotlib
